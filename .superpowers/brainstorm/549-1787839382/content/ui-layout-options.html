How would you like to view and edit translations?

Select the main UI layout for the extension webview

A

Translation Matrix / Data Grid (Recommended)

Spreadsheet-like table: rows are keys (home.title, auth.btn), columns are languages (en, vi, ja). Edit all languages inline, quickly spot missing translations.

B

Tree Navigator + Form Inspector

Nested folder-like tree on the left (e.g., auth > login > error). Selecting a key opens dedicated input fields/textareas for each language on the right.

C

Searchable Key List + Multi-Lang Panel

Flat searchable list of keys on the left with badges (e.g., 🔴 2 missing). Right pane shows side-by-side translation cards with rich diff/edit controls.
